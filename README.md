# HTML – HyperText Markup Language

## Description
This repository contains HTML programs and examples for beginners to learn the fundamentals of HTML (HyperText Markup Language). It covers the basic structure of web pages, elements, tags, attributes, headings, paragraphs, links, images, tables, lists, forms, and semantic HTML.

## Topics Covered
- Introduction to HTML
- HTML Document Structure
- Headings and Paragraphs
- Links and Images
- Lists and Tables
- Forms and Input Elements
- HTML Attributes
- Semantic HTML
- Audio and Video Elements
- HTML5 Features

## Technologies Used
- HTML
- HTML5
- Visual Studio Code

## Objective
The objective of this repository is to build a strong foundation in web development by learning how to structure web pages using HTML.
